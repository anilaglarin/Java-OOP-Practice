# 🚀 Java Object-Oriented Programming (OOP) Pratikleri

Bu depo, Java dilinde Nesne Yönelimli Programlama (OOP) kavramlarını pekiştirmek, mantığını anlamak ve uygulamaya dökmek için geliştirdiğim pratik çalışmaları içermektedir. 

Projeler, OOP'nin **4 temel prensibi** (Encapsulation, Inheritance, Polymorphism, Abstraction) başta olmak üzere, temel ve ileri seviye Java pratiklerini barındıran modüllerden oluşmaktadır.

## 📂 Depo İçeriği ve Proje Yapısı

Depo içerisindeki klasörler ve odaklandıkları temel konular şu şekildedir:

* **`Kalitim/`** Java'da *Inheritance (Kalıtım)* mekanizmasının incelendiği, sınıfların birbirinden nasıl türetildiğini ve kodun yeniden kullanılabilirliğini (reusability) gösteren örnekler.
  
* **`polimorfizm/`** *Polymorphism (Çok Biçimlilik)* prensibini ele alan; ata sınıfların (super class) referansları üzerinden alt sınıfların (sub class) metotlarının dinamik olarak nasıl çağrıldığını (Method Overriding) içeren pratikler.

* **`interface/`** & **`i2/`**, **`i3/`** Java'da tam soyutlama (Abstraction) sağlayan *Arayüzler (Interfaces)* ile gevşek bağlı (loosely coupled) sistemler kurma ve çoklu kalıtım simülasyonu üzerine çalışmalar.

* **`bahar/`**, **`ders3/`**, **`ehbe/`** Nesne ve sınıf yapısı oluşturma, *Encapsulation (Kapsülleme)*, erişim belirleyiciler (public, private, protected) ve kurucu metotlar (Constructor) gibi temel Java OOP pratikleri.

* **`FallManGame/`** OOP prensiplerini ve Java temel mantığını bir oyun yapısı (temel oyun mekanikleri ve akış yönetimi) üzerinde birleştirdiğim daha kapsamlı bir uygulama çalışması.

---

## 💡 OOP'nin 4 Temel Prensibi (Bu Depoda Neler Var?)

1. **Kapsülleme (Encapsulation):** Verileri (`private` değişkenler) koruma altına alıp, bunlara kontrollü bir şekilde `getter` ve `setter` metotları aracılığıyla erişim sağlama.
2. **Kalıtım (Inheritance):** `extends` anahtar kelimesi ile sınıflar arasında hiyerarşi kurarak kod tekrarını önleme.
3. **Çok Biçimlilik (Polymorphism):** Aynı metot isminin farklı sınıflarda farklı davranışlar sergilemesi (Overriding/Overloading).
4. **Soyutlama (Abstraction):** `interface` yapıları kullanarak detayları gizleyip sadece işlevleri ön plana çıkarma.
